మన వెలుగు

డిజిటల్ మీడియా — అడ్మిన్ ప్యానెల్

1. Supabase కనెక్షన్

మీ Supabase Project URL ముందే నింపబడింది. Supabase → Project Settings → API లోని Publishable/anon key ఇవ్వండి. Secret/service_role key ఇక్కడ ఎప్పుడూ పెట్టకండి.

ముందుగా కనెక్షన్ పరీక్షించండి.

2. అడ్మిన్ లాగిన్

Supabase Authలో ముందుగా అడ్మిన్ యూజర్ సృష్టించాలి.

3. వార్త ప్రచురించండి

వీడియో పెద్దదైతే అప్‌లోడ్‌కు ఎక్కువ సమయం పట్టవచ్చు. మొదట చిన్న వీడియోతో పరీక్షించండి.

వార్తలు ప్రచురించడానికి లాగిన్ అవ్వండి.

ఇటీవల ప్రచురించిన వార్తలు

సెటప్ గమనిక

ఈ అడ్మిన్ పేజీ పని చేయడానికి Supabaseలో news టేబుల్, news-media public bucket, RLS policies, మరియు Admin Auth user ఉండాలి. ఇవి ఇంకా సెటప్ చేయకపోతే publish పనిచేయదు. Public website కూడా అదే టేబుల్ నుంచి published వార్తలను చదివేలా కనెక్ట్ చేయాలి. ఈ ఫైల్‌ను GitHub repo rootలో admin.html పేరుతో పెట్టిన తర్వాత URL: /admin.html.
